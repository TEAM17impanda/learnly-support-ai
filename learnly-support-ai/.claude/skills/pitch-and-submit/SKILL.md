# Презентація і здача

## Структура слайдів (≤ 10) → критерії
| # | Слайд | Критерій |
|---|---|---|
| 1 | Назва, команда, one-liner | — |
| 2 | Проблема: support відповідає, але не вирішує (цифри/приклад) | Impact |
| 3 | Рішення: AI-операційний асистент поруч із командою | Use of AI |
| 4 | Як це працює: намір → справжня мета → дія → agent copilot (схема) | Reasoning |
| 5 | Демо-скріни + **відео** (вшити в презентацію) | Demo |
| 6 | AI-дії та guardrails: policy-guard, approve, audit log | Technical |
| 7 | Аналітика і якість підтримки (дашборд) | Impact |
| 8 | Архітектура + тести + fallback | Technical |
| 9 | Результати: час, врятовані учні, гроші (чесно: оцінка на мок-даних) | Impact |
| 10 | Roadmap + QR на деплой | Innovation |

## Принципи
- Один слайд — одна думка. Мінімум тексту, максимум схем і скрінів.
- Інновація = «розуміє справжню мету і замінює повернення на утримання», не «ще один чат-бот».
- Не обіцяй того, чого немає в MVP.

## Відеодемо
- 2–3 хв, сценарій з skill `demo-scenario`, озвучка або субтитри.
- Завантажити на Google Drive/YouTube unlisted → **доступ «для всіх за посиланням»**.
- Вставити відео/посилання прямо в презентацію.

## Код → ZIP
```bash
cd .. && zip -r learnly-support-ai.zip learnly-support-ai -x "*/.env" "*/__pycache__/*" "*/.pytest_cache/*" "*/.venv/*" "*/.git/*"
```
Перевір: `.env` не потрапив у архів, `README.md` з інструкцією запуску є, `pytest -q` зелений.
