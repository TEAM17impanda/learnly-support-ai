# Відповідальність модулів

| Модуль | Робить | НЕ робить |
|---|---|---|
| `app/data.py` | Мок-курси, потоки, учні, платежі, демо-повідомлення, історія | Логіка |
| `app/policy.py` | Константи політики + текст для промпту | Виконання |
| `app/context.py` | Похідні факти (дні з оплати, темп, дублі, можливості) | Зміна стану |
| `app/tools.py` | `check()` політики, `run()` зміни стану, реєстр `TOOLS` | Рішення «що пропонувати» |
| `app/agent.py` | Інтент, мета, reasoning, чернетка, пропозиція дій, LLM + fallback | Зміна стану учня |
| `app/quality.py` | Оцінка відповідей | Генерація відповідей |
| `app/store.py` | In-memory стан, audit log, налаштування | Бізнес-логіка |
| `app/main.py` | HTTP API, оркестрація, автономність, аналітика | Бізнес-правила |
| `static/index.html` | UI: черга, чат, панель копілота, дашборд | Правила (усе — з API) |

Принцип: **агент пропонує, `tools` вирішує і виконує, `main` оркеструє.**
