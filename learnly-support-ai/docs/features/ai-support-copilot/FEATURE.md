# AI Support Copilot

## Що це
Операційний AI-асистент для підтримки онлайн-школи Learnly. Працює поруч з агентом підтримки: розуміє звернення, визначає **справжню мету** учня, пропонує або виконує дії, готує відповідь і збирає аналітику.

## Навіщо
Звичайний чат-бот пояснює, але не діє. Тут AI закриває повний цикл: **намір → контекст → дія → відповідь → аналітика**.

## Ключові можливості
1. Розпізнавання наміру (7 типів) і справжньої мети (напр., «хоче повернення» ≠ «не вистачає часу»).
2. Дії через tools з policy-guard (8 дій, 3 рівні ризику).
3. Copilot для агента: reasoning з числами, чернетка відповіді, кнопки Approve/Reject.
4. Режими автономності: `copilot` / `auto_low_risk`.
5. Пріоритезація черги (P1–P3) і ризик відтоку (0–100).
6. Оцінка якості відповідей агентів (рубрика 100 балів) і дашборд.

## Межі MVP
In-memory дані, мок-учні, без авторизації. LLM опційний (є fallback на правила).
